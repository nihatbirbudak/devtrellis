# Contributing

Open an issue with the expected behavior, actual behavior, DevTrellis version and a minimal reproduction. English and Turkish reports are welcome. Remove API keys, personal notes, database files and full article bodies before sharing logs or screenshots.

For a code change, describe its scope and run the relevant Python or Node tests from README. Keep network and model tests deterministic with fake responses. Pull requests should explain any data migration or new external dependency.

See [PLATFORM.md](PLATFORM.md) for the developer platform scope, current limits and next contribution areas. Source suggestions should name the publisher, original feed/page URL, language, subject and the coverage gap they address. Research cards should include a focused question, dates, sources and uncertainties. Project cards should explain the problem, current state and how others can contribute. Do not describe planned hosted features as already available.

Code contributions are made under the project's MIT license. Keep third-party notices and do not submit code or content you lack permission to share. Card text permissions remain separate. Keep English and Turkish UI strings together and test both languages; do not translate user-authored content as an incidental side effect of changing interface language.
